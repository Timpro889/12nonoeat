# 2026-10-29

## 《蛋糕大胃王挑战》(index.html) 移动端自适应改造

问题：手机上底部按钮被截断，中间大片空白。

方案（已落地，全部在 index.html 内）：
- 新增 `--app-vh`：用 `window.visualViewport.height`（回退 innerHeight）写入，body 与 #app-container 高度改用该变量，彻底绕开 100vh 在移动端包含地址栏的溢出问题。
- 新增 `Layout` 对象：`apply()` 计算并写入 `--char-size`（角色正方形边长 = min(容器宽*0.94, 舞台剩余高-桌台高, 420)），`watch()` 绑定 resize / orientationchange / visualViewport resize+scroll / load / fonts.ready，用 rAF 合并重排。
- 角色区域用 `width=height=var(--char-size)` + 图片 `object-fit: contain`（素材 512x512），保证任何屏幕下都不变形；系数 0.94 是上限，因为 munch 动画 scale(1.14)、fever 动画 scale(1.06) 会再放大，超过会被裁切（曾试 1.12 导致大招手部被切）。
- 固定尺寸改为 clamp()：header 高、字号、按钮高、桌台、弹窗内距；控制区底部加 `env(safe-area-inset-bottom)`。
- Canvas 改为按 DPR 放大 + `setTransform`，逻辑坐标仍是 CSS 像素，新增 `Game.viewW/viewH` 替代 canvas.width/height 参与粒子计算。
- 弹窗 `.modal-dialog` 加 `max-height:100%; overflow-y:auto`，短屏可滚动不裁切。
- `.stage-area` 加柔光 radial-gradient 填充大屏留白；桌台加接地投影。

验证：Playwright 自带 chromium headless 截图 + dump-dom 校验 390x844 / 360x640 / 430x932 / 320x480 / 844x390，
scrollHeight == 视口高（无溢出）、char 宽高相等、无 JS 报错。
